## SD-WAN 拓扑视图大屏页面 — 实现完成

### 📁 文件结构
```
frontend/src/
├── App.tsx                              # 入口（渲染 TopologyView）
├── App.css                              # 暗色大屏主题样式（~600行）
├── index.css                            # 全局 CSS 变量 + 重置
└── pages/TopologyView/
    ├── index.tsx                        # 主页面布局（状态管理中心）
    ├── TopologyCanvas.tsx               # G6 5.x 拓扑画布组件
    ├── ControlBar.tsx                   # 左侧控制栏
    ├── ContextPanel.tsx                 # 右侧上下文面板
    └── mockData.ts                       # 模拟数据（拓扑/设备/策略/流量/故障）
```

### ✅ 6 大核心模块

| 模块 | 实现 |
|------|------|
| **1. 逻辑拓扑结构** | 11 个节点（HQ 六边形、6 分支圆形、vSmart 矩形、vBond 菱形、2 云网关椭圆），15 条 Overlay 隧道 |
| **2. 实时隧道状态** | 边标签显示 `🔒 带宽 | 延迟ms`，三色健康指示（绿/黄/红），Active 实线 + Standby 虚线 + Down 断线 |
| **3. 应用流量路径** | 应用流视图高亮 Zoom/SAP/Webex 路径，流量大小箭头，QoS 策略标注 |
| **4. 设备详情面板** | 右侧滑入面板：CPU/内存进度条、接口状态表、型号/版本/模板/运行时间、生效策略、故障 RCA |
| **5. 策略叠加层** | 切换"策略视图"后顶部浮层显示路由/QoS/安全三类策略 |
| **6. 故障根因分析** | 故障视图：红色闪烁节点 + 底部故障横幅 + 详情面板含根因/影响/建议 |

### 🎨 视觉设计

- **暗色科技风大屏**：深蓝背景 `#060b1a`，霓虹发光效果
- **节点样式**：每种设备类型独特形状 + 专属颜色（HQ 霓虹蓝 `#00b4d8`、分支电光紫 `#9d4edd`、vSmart 青色、vBond 金色）
- **粒子流动**：活跃隧道 `lineDash` 动画模拟流量方向
- **故障闪烁**：`@keyframes fault-flash` 红色脉冲动画

### 🕹️ 交互功能

- **4 种视图模式**：标准 / 应用流 / 策略 / 故障
- **搜索居中**：按设备名/类型搜索，自动聚焦 + 高亮
- **画布操作**：拖拽平移、滚轮缩放、点击选中、悬停高亮关联
- **面板固定**：📌 可固定右侧面板以便多节点对比
- **操作按钮**：导出拓扑（JSON）、模拟故障、下发策略
- **Minimap 小地图**：右下角缩略图

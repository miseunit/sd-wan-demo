#### 第 5 步：封装统一请求层

`services/api.js` 是前后端对接的核心，做了这些事：

1. **统一基础路径**：所有请求自动加 `/api/v1` 前缀
2. **自动加 Token**：请求头自动带 `Authorization: Bearer xxx`
3. **Token 过期自动刷新**：401 时自动用 refresh_token 换新 token
4. **统一解包响应**：后端返回 `{code, message, data}` → 前端直接拿到 `data`
5. **请求去重**：同一个 GET 请求不会发两次
6. **超时控制**：30 秒超时自动中断

```javascript
// 使用示例
import { get, post, put, del } from './api';

// 获取站点列表
const sites = await get('/sites/?page=1&pageSize=10');

// 创建站点
await post('/sites/', { name: '新站点', region: 'CN' });
```

### 2.2 建立设计 Token（设计令牌）

**什么是设计 Token？** 就是把所有视觉参数抽成变量，统一管理。

你需要先建一个文件 `index.css`，定义这些东西：

```
设计 Token 清单

│   ├── 文字色（3 级：标题 / 正文 / 辅助文字）
│   ├── 边框色（2 级：普通边框 / 强调边框）
│   ├── 主题色（青色 #00b4d8 —— 整个系统的"品牌色"）
│   └── 状态色（成功绿 / 警告黄 / 错误红 / 信息蓝）
├── 间距系统
│   ├── 4px / 8px / 12px / 16px / 20px / 24px
│   └── 卡片内边距 18-20px，页面边距 24px
```

### 2.3 深色/浅色双主题怎么设计？

**核心思路：同一套变量名，两套值。**

```css
/* 深色主题 */
[data-theme="dark"] {
    --bg-primary: #060b1a;      /* 深蓝黑底色 */
    --text-primary: #e0e0e0;    /* 浅灰文字 */
    --accent-cyan: #00b4d8;     /* 亮青色 */
}

/* 浅色主题 */
[data-theme="light"] {
    --bg-primary: #f5f7fa;      /* 浅灰白底色 */
    --text-primary: #0f172a;    /* 深色文字 */
    --accent-cyan: #0066cc;     /* 深蓝色（浅色下需要更深才看得清） */
}
```

**关键原则：**
- 浅色主题的主题色要比深色主题**更深**（对比度要求）
- 浅色主题的阴影要**更轻**（白色底上重阴影很丑）
- 浅色主题的光效（glow）要**减弱或去掉**（发光效果在白底上看不见）

### 2.4 组件设计规范

每个可复用组件都要定好状态：

```
按钮状态
├── 默认态：深色底 + 灰边框
├── 悬浮态：边框变主题色 + 文字变主题色
├── 点击态：微微缩小
├── 禁用态：半透明 + 禁止鼠标
└── 加载态：转圈图标

表格状态
├── 默认行：深色底
├── 悬浮行：底色变亮
├── 选中行：主题色底
├── 告警行：红色/黄色底（根据严重程度）
└── 禁用行：半透明

卡片状态
├── 默认：带边框 + 轻阴影
├── 悬浮：上浮 1px + 阴影增强 + 边框变亮
└── 点击：微微缩小
```

### 3.6 第六步：搭建状态管理

这个项目用了 React Context 管理两个全局状态：

```
状态管理
├── ThemeContext    → 管理深色/浅色主题
│   ├── theme: 'dark' | 'light'
│   ├── toggleTheme()
│   └── setTheme()
└── AuthContext     → 管理登录状态
    ├── user: { username, full_name }
    ├── isAuthenticated: boolean
    ├── login()
    └── logout()
```

**先做 ThemeContext（跟后端无关，纯前端就能跑）：**

```tsx
// src/contexts/ThemeContext.jsx
import { createContext, useContext, useState, useEffect } from 'react';

const ThemeContext = createContext();

export function ThemeProvider({ children }) {
    const [theme, setTheme] = useState(() => {
        return localStorage.getItem('my-theme') || 'dark';
    });

    useEffect(() => {
        document.documentElement.setAttribute('data-theme', theme);
        localStorage.setItem('my-theme', theme);
    }, [theme]);

    const toggleTheme = () => {
        setTheme(prev => prev === 'dark' ? 'light' : 'dark');
    };

    return (
        <ThemeContext.Provider value={{ theme, toggleTheme }}>
            {children}
        </ThemeContext.Provider>
    );
}

export const useTheme = () => useContext(ThemeContext);
```

然后在 `main.tsx` 里包裹：

```tsx
<ThemeProvider>
    <BrowserRouter>
        <App />
    </BrowserRouter>
</ThemeProvider>
```

```json
    "data": {

        "total": 100,
        "page": 1,
        "pageSize": 10
    }
}
```

**前端封装层自动解包：**

```javascript
// 前端调用
```

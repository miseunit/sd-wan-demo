## 当前问题

现在的表格用 Tailwind CSS，其中包含硬编码的颜色值：
- `text-white/90` - 白色半透明
- `bg-white/[0.04]` - 白色4%透明度
- `border-white/[0.04]` - 边框透明度

这些在浅色主题下完全不适配，所以需要大量 CSS 覆盖（800+ 行样式）。

## 用 Ant Design Table 的情况

### ✅ 更好的地方

1. **有明确的样式类名**
```css
/* 可以直接覆盖 */
.site-mgmt .ant-table {
  background: var(--bg-card);
}
.site-mgmt .ant-table-tbody > tr > td {
  color: var(--text-primary);
}
```

2. **通过 ConfigProvider 统一配置主题令牌**
```jsx
<ConfigProvider theme={{
  token: {
    colorBgContainer: 'var(--bg-card)',
    colorText: 'var(--text-primary)',
    // ...
  }
}}>
  <Table />
</ConfigProvider>
```

3. **不需要写那么多覆盖样式** - antd 会响应 CSS 变量变化

### ⚠️ 仍需注意的地方

从项目代码看，即使用了 antd 组件，仍然需要适配：
- 分页样式（已有 `.ant-pagination` 覆盖）
- Select 下拉框（已有 `.ant-select-selector` 覆盖）
- Drawer/Modal 等（已有 `.ant-drawer` 覆盖）

## 建议

**用 Ant Design Table 会比现在的方案简单很多**，主要优势：

1. 通过 ConfigProvider 配置一次主题令牌，大部分样式自动适配
2. 只需要少量 CSS 覆盖特殊情况
3. antd 6.x 的主题系统对 CSS 变量支持很好

如果要改，我可以帮你：
1. 把表格换成 antd Table

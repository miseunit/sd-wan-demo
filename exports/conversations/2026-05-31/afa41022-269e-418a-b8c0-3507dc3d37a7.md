### 🔧 核心改动

#### 1. 通用分页响应模型（[response.py](e:\case\sd-wan-demo\backend\app\schemas\response.py)）
```python
class PaginatedResponse(BaseModel, Generic[T]):
    items: List[T]      # 当前页数据列表
    total: int          # 总记录数
    page: int           # 当前页码（从1开始）
    pageSize: int      # 每页记录数
    totalPages: int   # 总页数
```

#### 2. API 参数统一
```python
# 修改前
skip: int = Query(0, ge=0)
limit: int = Query(100, ge=1, le=500)

# 修改后
page: int = Query(1, ge=1, description="页码（从1开始）")
pageSize: int = Query(10, ge=1, le=500, alias="pageSize", description="每页记录数")
```

#### 3. 计算逻辑
```python
# 获取总数
total = query.count()

# 计算 skip 值并获取分页数据
skip = (page - 1) * pageSize
items = query.order_by(...).offset(skip).limit(pageSize).all()

# 计算总页数
total_pages = (total + pageSize - 1) // pageSize if pageSize > 0 else 1
```

3. **类型安全**：使用 Generic 泛型，类型推断准确

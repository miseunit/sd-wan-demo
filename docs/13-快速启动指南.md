# SD-WAN 管理平台 — 快速启动指南

> **只需要 5 分钟，把项目跑起来。**
> 已经装好了 Node.js 和 Python 的情况下。

---

## 3 步启动

### 第 1 步：启动后端

```bash
cd backend
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Mac/Linux
pip install -r requirements.txt # 首次需要
uvicorn main:app --reload --port 8000
```

看到 `Application startup complete.` 就成功了。

### 第 2 步：启动前端（新开一个终端）

```bash
cd frontend
npm install                     # 首次需要
npm run dev
```

看到 `Local: http://localhost:5173/` 就成功了。

### 第 3 步：打开浏览器

访问 http://localhost:5173

| 地址 | 说明 |

| http://localhost:5173 | 前端页面 |
| http://localhost:8000 | 后端服务 |

| http://localhost:8000/health | 健康检查 |

## 一键启动（Windows）

双击项目根目录的 `start.bat` 文件。

---

## 重置数据库

```bash
# 停止后端（Ctrl+C）
del backend\data\app.db         # Windows
# rm backend/data/app.db        # Mac/Linux
# 重启后端（会自动重新填充种子数据）
```

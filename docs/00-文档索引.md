## 按角色找文档

### 我是零基础小白，从哪开始？

```
第 1 步：读 10-术语表.md（了解基本概念）
第 2 步：读 05-如何跟AI对话搭建项目.md（学会怎么问 AI）
第 3 步：读 08-部署与启动指南.md（把项目跑起来）
第 4 步：读 04-页面开发实战指南.md（开始做页面）
遇到问题：查 09-常见问题排查手册.md
```

### 我是前端开发，从哪开始？

```
第 1 步：读 01-设计规范.md（了解视觉规范）
第 2 步：读 02-前端架构指南.md（了解项目结构）
第 3 步：读 11-组件使用手册.md（了解公共组件）
第 4 步：读 04-页面开发实战指南.md（开始做页面）
对接后端时：查 06-API接口文档.md
```

### 我是后端开发，从哪开始？

```
第 1 步：读 03-后端架构指南.md（了解项目结构）
第 2 步：读 07-数据库模型文档.md（了解数据模型）
第 3 步：读 06-API接口文档.md（了解接口规范）
```

### 我要部署项目，从哪开始？

```
第 1 步：读 08-部署与启动指南.md
遇到问题：查 09-常见问题排查手册.md
```

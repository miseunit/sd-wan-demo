## 一、开发环境启动

### 1.1 前置条件

确保你的电脑上已安装：
- **Node.js** 20+（https://nodejs.org/）
- **Python** 3.10+（https://www.python.org/downloads/）

验证安装：

```bash
node -v      # 应显示 v20.x.x 或更高
npm -v       # 应显示 10.x.x 或更高
python --version  # 应显示 Python 3.10.x 或更高
```

### 1.2 首次启动（完整步骤）

#### 第一步：克隆/下载项目

```bash
# 如果用 Git
git clone <项目地址>
cd sd-wan-demo

# 或者直接下载解压
```

#### 第二步：启动后端

```bash
# 进入后端目录
cd backend

# 创建 Python 虚拟环境（仅首次）
python -m venv .venv

# 激活虚拟环境
# Windows:
.venv\Scripts\activate
# Mac/Linux:
source .venv/bin/activate

# 安装依赖（仅首次）
pip install -r requirements.txt

# 启动后端服务器
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

看到以下信息说明启动成功：

```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
INFO:     Started reloader process
INFO:     Application startup complete.
```

验证后端：
- 访问 http://localhost:8000/health — 应返回 `{"status": "healthy"}`
- 访问 http://localhost:8000/docs — 查看 API 文档

#### 第三步：启动前端（新开一个终端）

```bash
# 进入前端目录
cd frontend

# 安装依赖（仅首次）
npm install

# 启动前端开发服务器
npm run dev
```

看到以下信息说明启动成功：

```
VITE v8.x.x  ready in 300 ms

➜  Local:   http://localhost:5173/
```

#### 第四步：访问应用

打开浏览器访问 http://localhost:5173

### 1.3 日常启动

已经安装过依赖后，日常启动只需要：

```bash
# 终端 1：启动后端
cd backend
.venv\Scripts\activate     # Windows
uvicorn main:app --reload --port 8000

# 终端 2：启动前端
cd frontend
npm run dev
```

### 1.4 停止服务

在对应终端按 `Ctrl+C` 即可停止。

## 三、一键启动脚本

### Windows — start.bat

```bat
@echo off
echo ========================================
echo   SD-WAN 管理平台 启动脚本
echo ========================================
echo.

:: 启动后端
echo [1/2] 启动后端服务器...
cd /d %~dp0backend
start "SD-WAN Backend" cmd /k ".venv\Scripts\activate && uvicorn main:app --reload --port 8000"

:: 等待后端启动
timeout /t 3 /nobreak >nul

:: 启动前端
echo [2/2] 启动前端开发服务器...
cd /d %~dp0frontend
start "SD-WAN Frontend" cmd /k "npm run dev"

echo.
echo ========================================
echo   启动完成！
echo   前端: http://localhost:5173
echo   后端: http://localhost:8000
echo   API 文档: http://localhost:8000/docs
echo ========================================
pause
```

### Mac/Linux — start.sh

```bash
#!/bin/bash
echo "========================================"
echo "  SD-WAN 管理平台 启动脚本"
echo "========================================"

# 启动后端
echo "[1/2] 启动后端服务器..."
cd backend
source .venv/bin/activate
uvicorn main:app --reload --port 8000 &
BACKEND_PID=$!
cd ..

# 等待后端启动
sleep 3

# 启动前端
echo "[2/2] 启动前端开发服务器..."
cd frontend
npm run dev &
FRONTEND_PID=$!
cd ..

echo ""
echo "========================================"
echo "  启动完成！"
echo "  前端: http://localhost:5173"
echo "  后端: http://localhost:8000"
echo "  API 文档: http://localhost:8000/docs"
echo "========================================"

# 等待用户按 Ctrl+C
wait
```

## 四、环境变量配置

### 后端 .env 文件

在 `backend/` 目录下创建 `.env` 文件：

```env
# 数据库
DATABASE_URL=sqlite:///./data/app.db

# 应用
APP_NAME=SD-WAN Demo API
APP_VERSION=1.0.0
DEBUG=true

# CORS（前端地址）
CORS_ORIGINS=["http://localhost:5173","http://localhost:3000"]

# JWT
SECRET_KEY=your-secret-key-change-in-production
ACCESS_TOKEN_EXPIRE_MINUTES=30
REFRESH_TOKEN_EXPIRE_DAYS=7
```

### 前端 vite.config.ts

```typescript
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
    plugins: [react()],
    server: {
        port: 5173,
        proxy: {
            '/api': {
                target: 'http://localhost:8000',
                changeOrigin: true,
            },
        },
    },
});
```

## 五、重置数据库

如果需要清空所有数据重新开始：

```bash
# 1. 停止后端（Ctrl+C）

# 2. 删除数据库文件
# Windows:
del backend\data\app.db
# Mac/Linux:
rm backend/data/app.db

# 3. 重启后端
cd backend
uvicorn main:app --reload --port 8000
```

后端启动时会自动创建新的数据库并填充种子数据。

## 六、生产环境部署

### 6.1 构建前端

```bash
cd frontend
npm run build
```

构建产物在 `frontend/dist/` 目录。

### 6.2 部署方案

#### 方案一：Nginx 反向代理

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

#### 方案二：Docker

```dockerfile
# Dockerfile (后端)
FROM python:3.12-slim
WORKDIR /app
COPY backend/ .
RUN pip install -r requirements.txt
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

```yaml
# docker-compose.yml
version: '3.8'
services:
  backend:
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - "8000:8000"
    volumes:
      - ./backend/data:/app/data

  frontend:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./frontend/dist:/usr/share/nginx/html
      - ./nginx.conf:/etc/nginx/conf.d/default.conf
```

## 七、常见启动问题

### Q1: `npm install` 报错

```bash
# 清除缓存重试
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Q2: `pip install` 报错

```bash
# 确保虚拟环境已激活
# Windows:
.venv\Scripts\activate
# Mac/Linux:
source .venv/bin/activate

# 升级 pip
python -m pip install --upgrade pip

# 重新安装
pip install -r requirements.txt
```

### Q3: 后端启动报 "Address already in use"

端口 8000 被占用。要么关闭占用的进程，要么换端口：

```bash
# 换端口启动
uvicorn main:app --reload --port 8001
```

同时修改前端 `vite.config.ts` 中的 proxy target。

### Q4: 前端启动报 "Module not found"

```bash
# 重新安装依赖
rm -rf node_modules
npm install
```

### Q5: 数据库报错

```bash
# 删除数据库重新创建
rm backend/data/app.db
# 重启后端
```

### Q6: 跨域错误 (CORS)

检查后端 `main.py` 中的 CORS 配置是否包含前端地址：

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],  # 确保包含前端地址
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

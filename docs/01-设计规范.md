# SD-WAN 管理平台 — 设计规范文档

> **这份文档定义了整个项目的视觉规范。**
> 写任何页面的代码之前，先看这份文档。
> 所有颜色、字体、间距、圆角、阴影都必须按这里定义的来写。

---

## 一、设计风格概述

**风格定位：** 科技感深色主题 + 专业数据可视化，类似 NOC（网络运营中心）大屏幕。

**设计关键词：**
- 深蓝黑底色 + 青色高亮
- 信息层次分明（3 级背景色）
- 光效点缀（发光边框、脉冲动画）
- 数据驱动（大数字、状态标签、图表）

**双主题支持：**
- 深色主题（默认）— 科技感、专业感
- 浅色主题 — 清爽、企业级

## 二、颜色系统

### 2.1 背景色（3 级层次）

| 变量名 | 深色值 | 浅色值 | 用途 |
|--------|--------|--------|------|
| `--bg-primary` | `#060b1a` | `#f5f7fa` | 页面最底层背景 |
| `--bg-secondary` | `#0d1330` | `#ffffff` | 侧边栏、大区块背景 |
| `--bg-card` | `#0f1735` | `#ffffff` | 卡片内部背景 |
| `--bg-elevated` | `#151b3d` | `#ffffff` | 悬浮/激活时的背景 |
| `--bg-tertiary` | `#121840` | `#f8fafc` | 表头、输入框背景 |
| `--bg-overlay` | `rgba(6,11,26,0.95)` | `rgba(255,255,255,0.95)` | 弹窗遮罩 |

**使用原则：**
- 页面背景用 `--bg-primary`
- 侧边栏、大区块用 `--bg-secondary`
- 卡片、表格容器用 `--bg-card`
- 输入框、表头用 `--bg-tertiary`
- 悬浮状态用 `--bg-elevated`

### 2.2 文字色（3 级层次）

| 变量名 | 深色值 | 浅色值 | 用途 |
|--------|--------|--------|------|
| `--text-primary` | `#e0e0e0` | `#0f172a` | 标题、正文、重要数据 |
| `--text-secondary` | `#8892b0` | `#475569` | 说明文字、标签、表头 |
| `--text-muted` | `#555e7a` | `#94a3b8` | 时间戳、占位符、辅助信息 |
| `--text-disabled` | `#3d4663` | `#94a3b8` | 禁用状态文字 |

**使用原则：**
- 标题和正文用 `--text-primary`
- 表头、说明、次要信息用 `--text-secondary`
- 时间戳、占位符用 `--text-muted`
- 禁用状态用 `--text-disabled`

### 2.3 边框色

| 变量名 | 深色值 | 浅色值 | 用途 |
|--------|--------|--------|------|
| `--border-primary` | `#1e2a5c` | `#d1d5db` | 卡片边框、分割线 |
| `--border-secondary` | `#253270` | `#e5e7eb` | 更亮的边框、输入框边框 |
| `--border-active` | `#00b4d8` | `#0066cc` | 激活状态边框（主题色） |
| `--border-focus` | `#00b4d8` | `#0066cc` | 输入框聚焦边框 |

### 2.4 主题色

| 变量名 | 深色值 | 浅色值 | 用途 |
|--------|--------|--------|------|
| `--accent-cyan` | `#00b4d8` | `#0066cc` | 主色：按钮、链接、高亮、激活状态 |
| `--accent-cyan-light` | `#00d4ee` | `#0077ee` | 浅色变体 |

**为什么深色和浅色主题色不一样？**
深色背景上亮色更醒目，浅色背景上深色更清晰。这是对比度的要求。

### 2.5 功能色

| 变量名 | 深色值 | 浅色值 | 用途 |
|--------|--------|--------|------|
| `--accent-green` | `#00ff88` | `#10b981` | 成功、在线、健康 |
| `--accent-yellow` | `#ffdd00` | `#f59e0b` | 警告、需要注意 |
| `--accent-red` | `#ff4444` | `#ef4444` | 错误、离线、严重 |
| `--accent-purple` | `#9d4edd` | `#7c3aed` | 信息、特殊标记 |
| `--accent-gold` | `#ffd700` | `#f59e0b` | 高优先级 |

### 2.6 状态色（带背景色）

| 状态 | 文字色变量 | 背景色变量 |
|------|-----------|-----------|
| 成功/在线 | `--color-success` | `--color-success-bg` |
| 警告 | `--color-warning` | `--color-warning-bg` |
| 错误/离线 | `--color-error` | `--color-error-bg` |
| 信息 | `--color-info` | `--color-info-bg` |

背景色都是半透明的（如 `rgba(0, 255, 136, 0.1)`），用于表格行高亮、状态标签背景。

### 2.7 光效

| 变量名 | 深色值 | 浅色值 | 用途 |
|--------|--------|--------|------|
| `--glow-cyan` | `rgba(0,180,216,0.3)` | `rgba(0,102,204,0.15)` | 青色发光效果 |
| `--glow-green` | `rgba(0,255,136,0.3)` | `rgba(16,185,129,0.15)` | 绿色发光效果 |
| `--glow-red` | `rgba(255,68,68,0.3)` | `rgba(239,68,68,0.15)` | 红色发光效果 |

光效用于 `box-shadow` 和 `text-shadow`，深色主题下发光更明显，浅色主题下减弱。

### 2.8 链路类型专用色

| 变量名 | 值 | 用途 |
|--------|-----|------|
| `--link-mpls-color` | `#1890ff`（蓝色） | MPLS 链路 |
| `--link-internet-color` | `#52c41a`（绿色） | Internet 链路 |
| `--link-5g-color` | `#722ed1`（紫色） | 5G 链路 |

## 三、字体系统

### 3.1 字体族

```css
font-family: "Inter", system-ui, -apple-system, "Segoe UI", sans-serif;
```

数字和代码用等宽字体：
```css
font-family: 'JetBrains Mono', 'Fira Code', monospace;
```

### 3.2 字号规范

| 用途 | 字号 | 字重 | 行高 |
|------|------|------|------|
| 页面大标题 | 24px | 700 | 1.3 |
| 页面标题 | 22px | 600 | 1.3 |
| 区块标题 | 16px | 600 | 1.4 |
| 正文 | 14px | 400 | 1.5 |
| 辅助文字 | 13px | 500 | 1.4 |
| 小字/标签 | 12px | 500 | 1.3 |
| 极小字/角标 | 10-11px | 600 | 1.2 |
| 统计大数字 | 28px | 700-800 | 1.2 |
| 健康度大数字 | 36px | 800 | 1.0 |

### 3.3 数字显示

统计数据、延迟、丢包率等数字使用等宽字体 + `font-variant-numeric: tabular-nums`，保证数字对齐。

## 四、间距系统

统一使用以下间距值（单位 px）：

| 变量 | 值 | 用途 |
|------|-----|------|
| 极小间距 | 4px | 图标和文字之间 |
| 小间距 | 8px | 相关元素之间（如标签和内容） |
| 中间距 | 12px | 卡片内元素之间、筛选条件之间 |
| 标准间距 | 16px | 卡片之间、区块内元素之间 |
| 较大间距 | 20px | 卡片内边距 |
| 大间距 | 24px | 页面内容区内边距 |
| 超大间距 | 28-32px | 页面顶部内边距 |

**使用原则：**
- 紧凑型组件（标签、徽章）：4-8px
- 表单元素之间：16-20px
- 卡片之间：16px
- 页面边距：28-32px

## 六、阴影系统

| 变量名 | 深色值 | 浅色值 | 用途 |
|--------|--------|--------|------|
| `--shadow-sm` | `0 2px 8px rgba(0,0,0,0.4)` | `0 2px 8px rgba(0,0,0,0.08)` | 卡片默认阴影 |
| `--shadow-md` | `0 4px 16px rgba(0,0,0,0.5)` | `0 4px 16px rgba(0,0,0,0.1)` | 卡片悬浮阴影 |
| `--shadow-lg` | `0 8px 32px rgba(0,0,0,0.6)` | `0 8px 32px rgba(0,0,0,0.12)` | 弹窗阴影 |
| `--shadow-xl` | `0 16px 48px rgba(0,0,0,0.7)` | `0 16px 48px rgba(0,0,0,0.15)` | 特殊大阴影 |

**使用原则：**
- 深色主题阴影要重（0.4-0.7 不透明度），因为深色背景上轻阴影看不见
- 浅色主题阴影要轻（0.08-0.15 不透明度），因为白底上重阴影很丑

## 七、动画系统

### 7.1 过渡

```css
transition: all 0.2s ease;
```

- 过渡时间：0.2s（快速响应）
- 缓动函数：ease（自然减速）

### 7.2 常用动画效果

| 效果 | 实现 |
|------|------|
| 卡片悬浮 | `transform: translateY(-1px)` + 阴影增强 |
| 菜单项悬浮 | `transform: translateX(2px)` + 背景变亮 |
| 弹窗弹出 | `animation: fadeIn 0.2s ease` |
| 子菜单展开 | `animation: slideDown 0.2s ease` |
| 健康度脉冲 | `@keyframes pulse` 循环动画 |
| 呼吸光效 | `@keyframes glow-pulse` 循环动画 |

### 7.3 关键帧动画

```css
/* 脉冲环 */
@keyframes pulse-ring {
    0% { transform: scale(1); opacity: 0.6; }
    100% { transform: scale(1.6); opacity: 0; }
}

/* 呼吸光效 */
@keyframes glow-pulse {
    0%, 100% { opacity: 1; transform: scale(1); }
    50% { opacity: 0.7; transform: scale(1.15); }
}

/* 淡入 */
@keyframes fade-in {
    from { opacity: 0; }
    to { opacity: 1; }
}

/* 滑入 */
@keyframes slide-in {
    from { transform: translateX(20px); opacity: 0; }
    to { transform: translateX(0); opacity: 1; }
}
```

## 八、组件状态规范

### 8.1 按钮

| 状态 | 样式 |
|------|------|
| 默认 | 深色底 + 灰边框 + 浅色文字 |
| 悬浮 | 边框变主题色 + 文字变主题色 |
| 主按钮默认 | 主题色背景 + 白色文字 |
| 主按钮悬浮 | 主题色变亮 |
| 禁用 | 半透明 + 禁止鼠标 |
| 加载中 | 显示转圈图标 + 按钮禁用 |

### 8.2 表格

| 状态 | 样式 |
|------|------|
| 默认行 | `--bg-card` 背景 |
| 悬浮行 | `--bg-elevated` 背景 |
| 正常行 | 默认背景 |
| 警告行 | `--color-warning-bg` 黄色半透明背景 |
| 错误行 | `--color-error-bg` 红色半透明背景 |
| 表头 | `--bg-tertiary` 背景 + `--text-secondary` 文字 |

### 8.3 卡片

| 状态 | 样式 |
|------|------|
| 默认 | `--bg-card` 背景 + `--border-primary` 边框 + `--shadow-sm` 阴影 |
| 悬浮 | `transform: translateY(-1px)` + `--shadow-md` 阴影 + 边框变亮 |

### 8.4 状态标签

| 状态 | 背景色 | 文字色 | 示例 |
|------|--------|--------|------|
| 在线/成功 | `--color-success-bg` | `--color-success` | 🟢 在线 |
| 离线/错误 | `--color-error-bg` | `--color-error` | 🔴 离线 |
| 告警/警告 | `--color-warning-bg` | `--color-warning` | 🟡 告警 |
| 信息 | `--color-info-bg` | `--color-info` | 🔵 信息 |

标签样式：`padding: 3px 10px; border-radius: 20px; font-size: 12px; font-weight: 500;`

### 8.5 输入框

| 状态 | 样式 |
|------|------|
| 默认 | `--bg-tertiary` 背景 + `--border-primary` 边框 |
| 悬浮 | 边框变 `--border-secondary` |
| 聚焦 | 边框变 `--border-focus`（主题色）+ 发光效果 |
| 禁用 | 半透明 + 禁止输入 |

### 8.6 侧边栏菜单项

| 状态 | 样式 |
|------|------|
| 默认 | 透明背景 + `--text-secondary` 文字 |
| 悬浮 | 半透明白色背景 + 文字右移 2px + 图标变主题色 |
| 激活 | 主题色半透明背景 + 主题色文字 + 左侧发光指示条 |

激活指示条：宽 3px，高 24px，主题色，带发光效果（`box-shadow: 0 0 12px var(--glow-cyan)`）

## 十一、Ant Design 主题覆盖

通过 `ConfigProvider` 的 `theme` 属性覆盖 Ant Design 默认主题：

**深色主题：**
```js
{
    algorithm: antdTheme.darkAlgorithm,
    token: {
        colorPrimary: '#00b4d8',
        colorSuccess: '#00ff88',
        colorWarning: '#ffdd00',
        colorError: '#ff4444',
        colorBgBase: '#060b1a',
        colorBgContainer: '#0d1330',
        colorBorder: '#1a2555',
        colorText: '#e0e0e0',
        borderRadius: 6,
    }
}
```

**浅色主题：**
```js
{
    algorithm: antdTheme.defaultAlgorithm,
    token: {
        colorPrimary: '#0066cc',
        colorBgBase: '#f5f7fa',
        colorBgContainer: '#ffffff',
        colorBorder: '#d9d9d9',
        colorText: '#1a1a2e',
        borderRadius: 6,
    }
}
```

## 十二、代码中的颜色使用规则

**绝对禁止：**
```css
/* ❌ 写死颜色 */
.title { color: #e0e0e0; }
.card { background: #0d1330; }
```

**必须这样写：**
```css
/* ✅ 用 CSS 变量 */
.title { color: var(--text-primary); }
.card { background: var(--bg-secondary); }
```

**唯一允许写死颜色的场景：**
- CSS 变量定义文件（index.css）中
- 特殊的渐变色（如 `linear-gradient` 中的颜色）
- 链路类型专用色（可以用变量，也可以直接用值）

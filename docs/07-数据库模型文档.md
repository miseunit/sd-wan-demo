# SD-WAN 管理平台 — 数据库模型文档

> **这份文档详细描述了所有数据库表的结构。**
> 写后端代码或做数据库相关修改时看这份文档。

---

## 数据库配置

| 项目 | 值 |
|------|-----|
| 数据库引擎 | SQLite（开发环境） |
| 连接地址 | `sqlite:///./data/app.db` |
| ORM | SQLAlchemy 2.0（声明式映射） |
| 数据库文件 | `backend/data/app.db` |
| 初始化方式 | 应用启动时自动创建表 + 填充种子数据 |

---

## 表关系总览

```
users（用户表）— 独立

sites（站点表）
  ├── site_links（站点链路表）— 1:N
  ├── site_alerts（站点告警表）— 1:N
  └── site_history（站点历史数据表）— 1:N

devices（设备表）
  ├── device_interfaces（设备接口表）— 1:N
  ├── device_tunnels（设备隧道表）— 1:N
  ├── device_alerts（设备告警表）— 1:N
  └── device_upgrades（设备升级记录表）— 1:N

wan_links（WAN 链路表）
  ├── link_switch_events（链路切换事件表）— 1:N
  └── link_alerts（链路告警表）— 1:N

policies（策略表）— 独立
global_alerts（全局告警表）— 独立
```

## 一、users — 用户表

| 列名 | 类型 | 约束 | 说明 |

| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| email | VARCHAR(100) | UNIQUE, NOT NULL | 邮箱 |
| hashed_password | VARCHAR(200) | NOT NULL | 加密密码 |

## 种子数据说明

应用首次启动时，如果数据库为空，会自动填充以下测试数据：

| 表 | 数量 | 说明 |
|-----|------|------|
| users | 1 | 默认管理员 admin/admin123 |
| sites | 10-15 | 总部 + 各地分支 + 云端节点 |
| devices | 20-30 | 每个站点 2-3 台设备 |
| site_links | 30-50 | 每个站点 3-5 条链路 |
| wan_links | 30-50 | WAN 链路（与 site_links 同步） |
| global_alerts | 5-10 | 不同严重级别的告警 |
| policies | 5-8 | 路由策略、负载均衡、QoS 策略 |

**重置数据库：** 删除 `backend/data/app.db` 文件，重启后端即可。

## 五、统一响应格式

### 5.1 格式定义

**所有 API 接口都返回这个格式：**

```json
{
    "code": 200,
    "message": "获取成功",
    "data": { ... }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码（200=成功，4xx=客户端错误，5xx=服务器错误） |
| message | string | 提示消息 |
| data | any | 实际数据（成功时有值，失败时为 null） |

### 5.2 成功响应

```python
from app.schemas.response import success

# 返回列表
return success(data={
    "items": [...],
    "total": 100,
    "page": 1,
    "pageSize": 10,
})

# 返回单个对象
return success(data={"id": "site-01", "name": "北京总部"})

# 返回空（如删除操作）
return success(message="删除成功")
```

### 5.3 错误响应

```python
from app.schemas.response import error

return error(code=404, message="站点不存在")
return error(code=400, message="参数错误")
return error(code=500, message="服务器内部错误")
```

### 5.4 前端如何处理？

前端的 `api.ts` 会自动解包：

```tsx
// 后端返回 { code: 200, message: "成功", data: { items: [...] } }
// 前端直接拿到 data
const result = await get('/sites/');
// result = { items: [...], total: 100, page: 1, pageSize: 10 }
```

## 七、路由实现示例

### 7.1 站点管理 API

```python
# app/api/endpoints/sites.py
from fastapi import APIRouter, Depends
from sqlalchemy.orm import Session
from app.db import get_db
from app.models.site import Site
from app.schemas.response import success, error

router = APIRouter(prefix="/sites", tags=["站点管理"])

@router.get("/")
def list_sites(
    page: int = 1,
    pageSize: int = 10,
    region: str = None,
    status: str = None,
    search: str = None,
    db: Session = Depends(get_db)
):
    """获取站点列表（分页+筛选）"""
    query = db.query(Site)

    # 筛选
    if region:
        query = query.filter(Site.region == region)
    if status:
        query = query.filter(Site.status == status)
    if search:
        query = query.filter(Site.display_name.contains(search))

    # 分页
    total = query.count()
    items = query.offset((page - 1) * pageSize).limit(pageSize).all()

    # 转换为字典
    result = []
    for s in items:
        result.append({
            "id": s.id,
            "name": s.name,
            "displayName": s.display_name,
            "region": s.region,
            "status": s.status,
            "latency": s.latency,
            "loss": s.loss,
            "bandwidthUsage": s.bandwidth_usage,
            "siteType": s.site_type,
        })

    return success(data={
        "items": result,
        "total": total,
        "page": page,
        "pageSize": pageSize,
        "totalPages": (total + pageSize - 1) // pageSize,
    })

@router.get("/{site_id}")
def get_site(site_id: str, db: Session = Depends(get_db)):
    """获取站点详情"""
    site = db.query(Site).filter(Site.id == site_id).first()
    if not site:
        return error(code=404, message="站点不存在")
    return success(data={...})

@router.post("/")
def create_site(data: dict, db: Session = Depends(get_db)):
    """新增站点"""
    site = Site(
        id=f"site-{int(time.time())}",
        name=data["name"],
        display_name=data["displayName"],
        region=data["region"],
    )
    db.add(site)
    db.commit()
    return success(data={"id": site.id}, message="创建成功")

@router.put("/{site_id}")
def update_site(site_id: str, data: dict, db: Session = Depends(get_db)):
    """修改站点"""
    site = db.query(Site).filter(Site.id == site_id).first()
    if not site:
        return error(code=404, message="站点不存在")
    # 更新字段
    for key, value in data.items():
        if hasattr(site, key):
            setattr(site, key, value)
    db.commit()
    return success(message="更新成功")

@router.delete("/{site_id}")
def delete_site(site_id: str, db: Session = Depends(get_db)):
    """删除站点"""
    site = db.query(Site).filter(Site.id == site_id).first()
    if not site:
        return error(code=404, message="站点不存在")
    db.delete(site)
    db.commit()
    return success(message="删除成功")
```

## 八、种子数据

### 8.1 什么是种子数据？

种子数据是首次启动时自动填充到数据库的测试数据。没有种子数据，前端页面就是空的。

### 8.2 种子数据策略

**只在数据库为空时填充，不会覆盖已有数据。**

```python
# app/seed.py
def seed_all(db):
    """填充所有种子数据"""
    # 检查是否已有数据
    if db.query(Site).count() > 0:
        return  # 已有数据，跳过

    # 填充站点数据
    sites = [
        Site(id="site-bj-01", name="site-bj-01", display_name="北京总部",
             region="CN", status="online", latency=12, loss=0.01),
        Site(id="site-sh-01", name="site-sh-01", display_name="上海分支",
             region="CN", status="online", latency=18, loss=0.03),
        # ... 更多站点
    ]
    db.add_all(sites)

    # 填充设备数据
    # 填充链路数据
    # 填充告警数据

    db.commit()
```

### 8.3 种子数据量

| 模块 | 数量 | 说明 |
|------|------|------|
| 站点 | 10-15 条 | 总部 + 分支 + 云端 |
| 设备 | 20-30 台 | 每个站点 2-3 台设备 |

## 九、入口文件 main.py

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from app.core.config import settings
from app.db import init_db, seed_db
from app.api.endpoints import sites, devices, links, alerts, dashboard

@asynccontextmanager
async def lifespan(app: FastAPI):
    """应用生命周期管理"""
    # 启动时初始化数据库并填充种子数据
    init_db()
    seed_db()
    yield

# 创建应用
app = FastAPI(
    title=settings.APP_NAME,
    version=settings.APP_VERSION,
    lifespan=lifespan,
)

# 配置 CORS（允许前端跨域请求）
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.CORS_ORIGINS,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# 注册路由
app.include_router(sites.router, prefix=settings.API_PREFIX)
app.include_router(devices.router, prefix=settings.API_PREFIX)
app.include_router(links.router, prefix=settings.API_PREFIX)
app.include_router(alerts.router, prefix=settings.API_PREFIX)
app.include_router(dashboard.router, prefix=settings.API_PREFIX)

@app.get("/health")
def health_check():
    """健康检查"""
    return {"status": "healthy"}
```

## 十二、统一响应中间件

为了让所有接口自动返回 `{code, message, data}` 格式，项目使用了一个 ASGI 中间件：

**中间件做了什么？**
1. 拦截所有 `/api/v1/` 开头的请求
2. 如果接口返回的是裸数据（如 `[1,2,3]`），自动包装为 `{code: 200, message: "成功", data: [1,2,3]}`
3. 如果接口返回的已经是统一格式，不重复包装
4. 204 No Content 响应包装为 `{code: 200, message: "删除成功", data: null}`

**好处：** 接口代码只需要返回数据，不需要每次都写 `success(data=xxx)`。

## 十三、异常处理

全局异常处理确保任何错误都返回统一格式：

```python
# HTTP 异常（404、400 等）
@app.exception_handler(StarletteHTTPException)
async def http_exception_handler(request, exc):
    return JSONResponse(
        status_code=exc.status_code,
        content=error(code=exc.status_code, message=str(exc.detail)),
    )

# 参数校验异常
@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc):
    return JSONResponse(
        status_code=422,
        content=error(code=422, message="参数校验失败"),
    )

# 未知异常（防止内部错误信息泄露）
@app.exception_handler(Exception)
async def global_exception_handler(request, exc):
    return JSONResponse(
        status_code=500,
        content=error(code=500, message="服务器内部错误"),
    )
```

## 十四、常见问题

### Q: 数据库文件在哪里？

SQLite 数据库文件在 `backend/data/app.db`。删除这个文件，重启后端会自动重新创建并填充种子数据。

### Q: 怎么重置数据库？

```bash
# 删除数据库文件
rm backend/data/app.db

# 重启后端（会自动重新创建并填充种子数据）
uvicorn main:app --reload --port 8000
```

### Q: 怎么修改种子数据？

编辑 `backend/app/seed.py` 文件，修改里面的测试数据，然后重置数据库。

### Q: API 返回 422 错误？

422 是参数校验失败。检查请求参数是否符合接口定义（类型、必填项等）。

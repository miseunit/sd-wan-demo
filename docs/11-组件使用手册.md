## 一、通用样式类（CSS Class）

这些样式类定义在 `src/styles/theme.css` 中，所有页面都可以直接用，不需要 import。

### 1.1 页面标题栏

```html

    <div class="page-header__left">
        <h1 class="page-header__title">页面标题</h1>
```

效果：左边标题+副标题，右边操作按钮，两端对齐。

## 二、Ant Design 组件主题适配

项目通过 CSS 覆盖了 Ant Design 组件的默认样式，以下组件已经适配深色主题：

| 组件 | 适配内容 |
|------|---------|
| Table | 表头背景、行悬浮、文字颜色 |
| Button | 默认样式、主按钮、危险按钮 |
| Input | 背景色、边框色、聚焦效果 |
| Select | 下拉框背景、选项悬浮 |
| Pagination | 页码背景、激活状态 |
| Modal | 弹窗背景、边框 |
| Tag | 各种颜色的标签 |
| Badge | 徽章颜色 |
| Progress | 进度条颜色 |
| Segmented | 分段选择器 |

**直接使用这些组件就行，不需要额外写样式。**

## 三、主题切换

### useTheme Hook

```tsx
import { useTheme } from '../contexts/ThemeContext';

function MyComponent() {
    const { theme, toggleTheme } = useTheme();

    return (
        <div>
            <p>当前主题：{theme}</p>
            <button onClick={toggleTheme}>切换主题</button>
        </div>
    );
}
```

| 返回值 | 类型 | 说明 |
|--------|------|------|
| theme | `'dark' \| 'light'` | 当前主题 |
| toggleTheme | `() => void` | 切换深色/浅色 |

## 四、认证相关

### useAuth Hook

```tsx
import { useAuth } from '../contexts/AuthContext';

function MyComponent() {
    const { user, isAuthenticated, login, logout } = useAuth();

    if (!isAuthenticated) {
        return <div>请先登录</div>;
    }

    return (
        <div>
            <p>欢迎，{user.full_name || user.username}</p>
            <button onClick={logout}>退出登录</button>
        </div>
    );
}
```

| 返回值 | 类型 | 说明 |
|--------|------|------|
| user | `object \| null` | 当前用户信息 |
| isAuthenticated | `boolean` | 是否已登录 |
| isLoading | `boolean` | 是否正在检查登录状态 |
| login | `(username, password) => Promise` | 登录方法 |
| logout | `() => void` | 退出登录 |

## 五、路由守卫

### ProtectedRoute — 受保护路由

未登录用户访问时，自动跳转到登录页。

```tsx
import ProtectedRoute from '../components/ProtectedRoute';

<Route element={<ProtectedRoute />}>
    <Route path="/sites" element={<SiteManagement />} />
</Route>
```

### PublicRoute — 公开路由

已登录用户访问时，自动跳转到首页。

```tsx
import PublicRoute from '../components/PublicRoute';

<Route element={<PublicRoute />}>
    <Route path="/login" element={<Login />} />
</Route>
```

## 六、API 请求

### 基础请求函数

```tsx
import { get, post, put, del } from '../services/api';

// GET 请求
const data = await get('/sites/?page=1');

// POST 请求
await post('/sites/', { name: '新站点', region: 'CN' });

// PUT 请求
await put('/sites/site-01', { displayName: '新名称' });

// DELETE 请求
await del('/sites/site-01');
```

所有函数自动处理：
- 添加 `/api/v1` 前缀
- 添加 Authorization Token
- 解包 `{code, message, data}` 响应
- 错误处理

## 七、路由配置

在 `App.tsx` 中添加新页面的路由：

```tsx
import NewPage from './pages/NewPage';

// 在 AppLayout 的 Route 下面添加：
<Route path="/new-page" element={<NewPage />} />
```

同时在 `AppLayout.tsx` 的 `menuItems` 中添加菜单项：

```tsx
const menuItems = [
    // ... 已有菜单
    { key: 'new', label: '新页面', icon: <XXXOutlined />, path: '/new-page' },
];
```

## 八、页面标准模板

每个管理页面都可以用这个模板：

```tsx
import { useState, useMemo } from 'react';
import { Input, Select, Button, Table, Tag, Space, Modal, message } from 'antd';
import { SearchOutlined, PlusOutlined, EditOutlined, DeleteOutlined } from '@ant-design/icons';
import './XxxPage.css';

export default function XxxPage() {
    const [data, setData] = useState([]);
    const [search, setSearch] = useState('');
    const [modalOpen, setModalOpen] = useState(false);
    const [editing, setEditing] = useState(null);

    const filtered = useMemo(() => {
        return data.filter(item => {
            if (search && !item.name.includes(search)) return false;
            return true;
        });
    }, [data, search]);

    const handleDelete = (id) => {
        Modal.confirm({
            title: '确认删除',
            onOk: () => {
                setData(prev => prev.filter(item => item.id !== id));
                message.success('删除成功');
            },
        });
    };

    const columns = [
        { title: '名称', dataIndex: 'name' },
        { title: '状态', dataIndex: 'status', render: v => <Tag>{v}</Tag> },
        { title: '操作', render: (_, r) => (
            <Space>
                <Button size="small" onClick={() => { setEditing(r); setModalOpen(true); }}>编辑</Button>
                <Button size="small" danger onClick={() => handleDelete(r.id)}>删除</Button>
            </Space>
        )},
    ];

    return (
        <div className="xxx-page">
            <div className="page-header">
                <h1 className="page-header__title">XXX 管理</h1>
                <Button type="primary" icon={<PlusOutlined />} onClick={() => { setEditing(null); setModalOpen(true); }}>
                    新增
                </Button>
            </div>

            <div className="filter-bar">
                <Input placeholder="搜索" prefix={<SearchOutlined />} value={search} onChange={e => setSearch(e.target.value)} style={{ width: 200 }} />
                <span>共 {filtered.length} 条</span>
            </div>

            <div className="table-wrapper">
                <Table dataSource={filtered} columns={columns} rowKey="id" />
            </div>
        </div>
    );
}
```

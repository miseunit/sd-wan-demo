# 如何跟 AI 对话搭建 SD-WAN 管理平台

> **这份文档教你如何跟 AI 配合，一步步把项目做出来。**
> 你不需要会写代码，只需要会描述你想要什么。

---

## 核心原则

跟 AI 对话就记住一句话：**说清楚你想要什么效果，AI 帮你写代码。**

你不需要懂技术术语，用大白话描述就行。比如：

- ✅ "帮我做一个登录页面，中间一个卡片，上面有 logo，下面是用户名密码输入框和登录按钮"
- ❌ "帮我实现一个基于 JWT 的 OAuth2.0 认证流程"（这是专业术语，小白不需要这样说）

---

## 第一步：告诉 AI 你要做什么

一开始就跟 AI 说清楚你的项目是什么：

```
我要做一个 SD-WAN 网络管理平台，用来看管公司各个办公室的网络状态。

技术栈：
- 前端：React + Vite + TypeScript + Ant Design
- 后端：FastAPI + SQLAlchemy + SQLite

先帮我创建项目，建好文件夹结构，安装好依赖。
```

AI 会帮你执行命令、创建文件夹、安装依赖。等它做完，你再进行下一步。

---

## 第二步：建立设计规范

告诉 AI 你想要什么风格：

```
我要做一个深色科技风的管理平台，类似电影里那种控制中心的感觉。

帮我定义一套设计规范，包括：
- 两套主题：深色（默认）和浅色
- 背景色分 3 级：最深的页面底色、中间的卡片底色、最浅的浮层底色
- 文字色分 3 级：标题、正文、辅助文字
- 主题色用青色
- 状态色：绿色=在线/成功、红色=离线/错误、黄色=警告

所有颜色用 CSS 变量定义，不写死。
```

AI 会生成一个 CSS 文件，里面定义了所有颜色变量。这个文件是整个项目的"调色板"。

---

## 第三步：搭建布局

告诉 AI 你想要什么布局：

```
帮我做一个全局布局，左边是侧边栏，右边是内容区。

侧边栏：
- 宽 220 折叠后 64
- 上面显示 "SD-WAN" 品牌
- 中间有菜单：站点管理、链路管理、设备管理、策略管理、告警中心
- 下面有个折叠按钮
- 菜单项点击后高亮

右边内容区自动撑满，用来显示各个页面。
```

AI 会创建布局组件和样式文件。

---

## 第四步：开始做页面

### 做页面的标准问法

每个页面都按这个套路跟 AI 说：

```
帮我做 [页面名称] 页面。

从上到下的布局是：
1. 标题栏，左边标题右边按钮
2. 统计卡片，显示总数、在线数、离线数、告警数
3. 筛选栏，有搜索框和下拉筛选
4. 数据表格，列有：名称、状态、延迟、操作
5. 新增/编辑用弹窗

先用假数据，后面对接真实 API。
```

### 登录页

```
帮我做登录页。

居中显示一个登录卡片，上面有 "SD-WAN" 的 logo 和标题，
logo 要有青色发光效果。然后是用户名输入框、密码输入框、
记住用户名复选框、登录按钮（全宽，主题色），
最下面有"去注册"的链接。

表单要验证，用户名必填最少 3 个字，密码必填最少 6 个字。
```

### 首页

```
帮我做首页，是一个总览页面。

上面是一个欢迎横幅，左边标题"SD-WAN 网络管理中心"，
右边显示健康度大数字。中间 6 个指标卡片排成一行。
下面分左右两栏，左边是快速操作（可点击跳转），
右边是最近告警列表。
```

### 站点管理

```
帮我做站点管理页面，这是最核心的页面。

从上到下：
1. 标题"站点管理"，右边有刷新和新增按钮
2. 4 个统计卡片：总站点、在线、离线、告警
3. 筛选栏：搜索框 + 区域下拉 + 状态下拉
4. 数据表格，列有：
   - 站点名称（大字+小字编码）
   - 区域（带国旗 emoji）
   - 状态（绿色=在线、红色=离线、黄色=告警）
   - 延迟
   - 丢包率
   - 带宽使用率
   - 操作（编辑、删除）
5. 点新增弹出表单弹窗，有站点名称、编码、区域、类型
6. 删除要弹确认框

先用 5 条假数据。
```

## 第五步：对接后端

当前端页面都做好了，告诉 AI 搭建后端：

```
现在帮我搭建后端。

数据模型有：站点、设备、链路、告警。
所有接口返回统一格式 { code: 200, message: "成功", data: {...} }。

API 有：
- 站点的增删改查
- 设备的增删改查
- 链路的增删改查
- 告警的增删改查（含确认和静默操作）

启动时自动填充测试数据（10 个站点、20 台设备等）。
```

然后对接前端：

```
帮我把前端跟后端对接起来。

配置 Vite 代理把 /api 请求转发到后端。
创建统一的请求封装文件，自动处理后端返回的 {code, message, data} 格式。
然后修改站点管理页面，把假数据换成真实 API 调用。
```

## 第六步：做特殊页面

### 拓扑图

```
帮我做网络拓扑图页面。

用 @antv/g6 画。节点代表站点，总部用大圆、分支用小圆。
节点之间用线连接代表链路，不同颜色区分 MPLS/Internet/5G。
节点可以拖拽，支持缩放。点击节点显示详情。
```

### 监控大屏

```
帮我做全网监控大屏。

上面显示关键指标（健康度、在线数、带宽、告警数）。
左边一个地图或拓扑，右边一个实时流量曲线图。
下面三列：应用流量饼图、站点排行、ISP 带宽分布。
数据每 5 秒自动刷新。
```

---

## 第七步：打磨优化

```
帮我做最后的优化：

1. 检查所有页面颜色是否都用了 CSS 变量，有没有写死的
2. 所有删除操作加确认弹窗
3. 所有操作加提示（成功/失败）
4. 搜索加防抖（不要每次按键都请求）
5. 表格没数据时显示"暂无数据"
6. 检查深色和浅色两种主题是否都正常
7. 小屏幕适配（手机、平板）
```

## 遇到问题怎么办？

### 代码报错了

直接把报错信息复制给 AI：

```
报错了：
[粘贴错误信息]
帮我修。
```

### 想改某个功能

描述你想要的效果：

```
现在登录成功后直接跳到首页，
我想改成跳到用户之前想访问的那个页面。
```

### 不知道怎么描述

用最简单的话：

```
我想要一个表格，能搜索、能筛选、能新增、能编辑、能删除。
就像 Excel 那样，但是在网页上。
```

### 想加新功能

```
在站点管理页面加一个"批量重启"功能，
用户勾选多个站点后，点一个按钮就能批量重启。
要显示进度条。
```

## 对话节奏

不要一次让 AI 做太多事情。正确的节奏是：

```
你：帮我创建项目
AI：（创建完了）
你：帮我建设计规范
AI：（建完了）
你：帮我做布局
AI：（做完了）
你：帮我做登录页
AI：（做完了）
你：帮我做首页
AI：（做完了）
你：帮我做站点管理
AI：（做完了）
...
```

**每一步都等 AI 做完了再进行下一步。** 这样出错了容易定位，改起来也方便。

---

## 最后记住

1. **AI 不会嫌你问得多** — 大胆问，问得越细越好
2. **先做简单的再做复杂的** — 登录 → 首页 → 管理页 → 拓扑图
3. **先用假数据** — 不要一开始就对接后端，先把页面做出来
4. **遇到问题就问** — 把报错信息给 AI，它会帮你修
5. **做完一个页面再做下一个** — 不要同时做好几个

**最重要的一句话：不要想太多，先说第一句话，让 AI 帮你开始。**

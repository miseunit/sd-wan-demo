# SD-WAN 管理平台 — 代码规范检查清单

> **提交代码前，按这份清单逐项检查。**
> 确保代码质量一致，风格统一。

---

## 一、前端代码检查

### 1.1 颜色

- [ ] 所有颜色都用 `var(--xxx)` CSS 变量，没有写死 `#xxx`
- [ ] 深色/浅色主题下都测试过
- [ ] 状态色用的是语义化变量（`--accent-green` 而不是 `#00ff88`）

### 1.2 样式

- [ ] CSS 文件被正确 import（`import './Xxx.css'`）
- [ ] 类名用 BEM 命名法（`block__element--modifier`）
- [ ] 间距用的是标准值（4/8/12/16/20/24/32px）
- [ ] 圆角用的是标准值（6/8/12/16/20px）
- [ ] 没有使用 `!important`（除非覆盖 Ant Design 样式）
- [ ] 滚动条样式自定义（4px 宽）

### 1.3 组件

- [ ] 组件有 `export default`
- [ ] import 路径正确（大小写匹配）
- [ ] 文件名用 PascalCase（`SiteManagement.tsx`）
- [ ] 没有未使用的 import
- [ ] 没有 `console.log`（调试用的要删掉）

### 1.4 状态管理

- [ ] `useEffect` 有依赖数组
- [ ] `useEffect` 中的定时器在 return 中清除
- [ ] `useState` 初始值类型正确
- [ ] 事件处理函数用 `useCallback` 包裹（如果传给子组件）

### 1.5 表格

- [ ] `rowKey` 属性设置正确（唯一标识）
- [ ] `columns` 中的 `dataIndex` 跟数据字段名一致
- [ ] 分页配置正确（`pageSize`、`showTotal`）
- [ ] loading 状态正确绑定
- [ ] 空数据时有友好提示

### 1.6 表单

- [ ] 必填字段有 `rules={[{ required: true }]}`
- [ ] 表单有验证（`form.validateFields()`）
- [ ] 提交按钮有 loading 状态
- [ ] 编辑时自动填充数据（`form.setFieldsValue()`）
- [ ] 关闭弹窗时清空表单（`form.resetFields()`）

### 1.7 交互

- [ ] 删除操作有 `Modal.confirm` 二次确认
- [ ] 操作成功/失败有 `message.success/error` 提示
- [ ] 搜索有防抖（300ms）
- [ ] 按钮点击后禁用（防止重复提交）
- [ ] Esc 键可以关闭弹窗

## 二、后端代码检查

### 2.1 命名

- [ ] 文件名用 snake_case（`site_management.py`）
- [ ] 函数名用 snake_case（`list_sites`）
- [ ] 类名用 PascalCase（`SiteManagement`）
- [ ] 常量用 UPPER_SNAKE_CASE（`MAX_PAGE_SIZE`）

### 2.2 API 路由

- [ ] URL 用 kebab-case（`/api/v1/sites/`）
- [ ] GET 返回列表用分页格式（`{items, total, page, pageSize}`）
- [ ] POST 返回创建的对象或 ID
- [ ] PUT/PATCH 返回更新后的对象
- [ ] DELETE 返回 204 或成功消息
- [ ] 错误返回统一格式（`{code, message, data: null}`）

### 2.3 数据库

- [ ] 模型有 `created_at` 和 `updated_at` 字段
- [ ] 外键关系正确定义
- [ ] 索引添加在常用查询字段上
- [ ] 字段有 `comment` 说明

### 2.4 错误处理

- [ ] 404 错误有明确的错误消息
- [ ] 422 参数校验有详细的错误信息
- [ ] 500 错误不暴露内部信息
- [ ] 数据库操作有 try/except

### 2.5 安全

- [ ] 密码不以明文存储（用 bcrypt）
- [ ] 敏感信息不在响应中返回（密码、token）
- [ ] CORS 配置正确（不要用 `*` 在生产环境）
- [ ] SQL 查询用 ORM（不要拼接 SQL）

## 三、Git 提交检查

### 3.1 提交信息格式

```
<类型>(<范围>): <描述>

类型：
- feat: 新功能
- fix: 修复 bug
- style: 样式修改（不影响功能）
- refactor: 重构（不改变功能）
- docs: 文档
- test: 测试
- chore: 构建/工具

示例：
feat(sites): 新增站点批量操作功能
fix(alerts): 修复告警确认后状态未更新的问题
style(home): 调整首页指标卡片间距
```

### 3.2 提交前检查

- [ ] 没有提交 `node_modules/` 目录
- [ ] 没有提交 `.venv/` 目录
- [ ] 没有提交 `data/app.db` 数据库文件
- [ ] 没有提交 `.env` 环境变量文件
- [ ] 没有提交调试用的 `console.log`
- [ ] 代码能正常运行（没有语法错误）
